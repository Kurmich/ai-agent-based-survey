# AI-based audio survey project

This is an AI-agent based survey collection project.

Use
+ *data_cleaner.ipynb* to transform original survey data to the survey that will be conducted using AI agents.
+ *generate_scripts.ipynb* to generate sample transcripts that could be used for responses.
+ *blandai_caller.ipynb* to send agent calls.
+ *analyze_transcripts.ipynb* to analyze resulting transcripts.
